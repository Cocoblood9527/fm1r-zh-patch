《前线任务 初代 重制版》繁体中文汉化补丁 — 安装说明

适用版本：v.3.0.1（Unity 2021.3.6f1，Windows 64 位 Mono 版）
补丁形式：BepInEx 插件，不修改游戏原始文件


一、安装（Windows）

1. 完全关闭游戏。
2. 把本压缩包里的全部内容解压到游戏根目录，也就是和
   "FRONT MISSION 1st Remake.exe" 同一个文件夹。
   解压后该文件夹里应该出现：
       BepInEx\
       winhttp.dll
       doorstop_config.ini
3. 启动游戏，游戏内语言选择「繁體中文」即可看到汉化文本。

Windows 到这一步就结束了，不需要设置任何东西：
    Steam 的「右键游戏 → 属性 → 通用 → 启动选项」请保持空白。
本补丁不需要、也不识别任何命令行参数或环境变量。
（第五节的 WINEDLLOVERRIDES 是给 Linux / Steam Deck 用的，Windows 不要填。）

首次启动会慢几秒，因为补丁要把额外的汉字现场绘制成字形，之后会快很多。


二、卸载

删除游戏根目录下的这三样即可，游戏回到原版状态：
    BepInEx\
    winhttp.dll
    doorstop_config.ini


三、想确认补丁有没有生效

看游戏里这些词：
    生效：設置 / 新手機師指南 / 工作人員列表 / 平滑處理 (ANTI-ALIASING)
    未生效（原版机翻）：配置 / 新手指南 / 制作人员名单 之类
也可以打开 BepInEx\LogOutput.log，里面应有
    [FM1R Chinese Translation] 读入 8198 条文本
    [FM1R Dynamic Glyph Fallback] 已挂到 ... 个字体资产的 fallback 链首位


四、点了启动却没进游戏，弹窗「Windows 找不到文件」

如果弹窗里的文件名是 WINEDLLOVERRIDES=winhttp=n,b，说明「启动选项」里
被贴进了第五节那条 Linux / Steam Deck 专用命令。Windows 的 Steam 会把这串
文字当成一个程序名去找，自然找不到，游戏根本没启动。

处理：Steam → 右键游戏 → 属性 → 通用 → 启动选项 → 把整栏清空 → 确定。
这不会影响补丁，游戏和解压出来的文件都没有任何损坏，也不需要重新解压。


五、仅 Linux / Steam Deck（Proton）——Windows 用户请跳过本节

上面的 winhttp.dll 需要让 Wine 优先加载游戏目录里的版本。在 Steam 里
右键游戏 → 属性 → 通用 → 启动选项，填入：

    WINEDLLOVERRIDES="winhttp=n,b" %command%

然后把解压出来的文件放进 Proton 前缀对应的游戏目录（兼容数据包）里。

不填这条的话，Unity 会加载 Proton 自带的 winhttp，BepInEx 的注入入口不会被
触发，游戏看起来正常启动但仍是原版机翻。

这条命令用的是 Wine 的环境变量语法，只在 Linux / Steam Deck 上有效；
Windows 上填了只会得到第四节那个报错。


六、已知限制

作战简报（－作戰要項－）只显示一行内容，日文与英文原文同样如此，
这是游戏自身的布局限制，不是汉化造成的。其余界面不受影响。


七、自己改文本

见「edit-text.txt」（如何自己改文本）。不需要重新编译任何东西。
