怎么自己改汉化文本（edit-text）

文本表位置：
    BepInEx\plugins\FM1RZhPatch\zh.csv

格式：UTF-8 编码的两列表格，第一行是表头。
    key,zh
    ui_settings,"設置"
    msg_com_ofi1,"奧爾森：
    任務情報在這裡。"

要点：
1. 第一列 key 是游戏的文本编号，绝对不要改、不要删、不要重复。
2. 第二列是显示出来的文字。文字里如果有换行或半角逗号，整格必须用英文
   双引号包起来；文字内部要出现双引号，就写成两个连续的双引号。
3. 用 Excel / WPS 打开编辑最省事，保存时选「CSV UTF-8」。
   保存后确认文件开头是 key,zh 而不是带 BOM 的乱码。
4. 改完直接进游戏，不需要重新编译任何东西。

关于缺字（显示成 □）：
    游戏自带的中文字体只包含约 3200 个字形，超出的一律显示成方框。
    本补丁已经挂了一套动态字体（Noto Sans CJK TC）来兜底，所以你可以
    放心使用任何常用汉字；如果某个字仍然显示成方框，说明该字形不在
    Noto Sans CJK 覆盖范围内，换一个写法即可。

想换字体：
    把任意 TTF/OTF 放进 BepInEx\plugins\ 目录（和 FM1RGlyphFix.dll 同级），
    补丁会自动用它作为兜底字形来源。


恢复出厂汉化

删掉 BepInEx\plugins\FM1RZhPatch\zh.csv 即可让文本回到游戏自带的机翻版本
（字体兜底仍然保留）。
