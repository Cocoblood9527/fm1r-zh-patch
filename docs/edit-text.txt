怎么自己改汉化文本（edit-text）

文本表位置：
    BepInEx\plugins\FM1RZhPatch\zh.csv

格式：UTF-8 编码的 CSV，第一行必须是表头。共五列，插件只认 key 和 zh 两列，
列的顺序可以随便调，多加的列会被忽略。

    key,flag,zh,jp_original,en

  key          游戏内部的文本编号。不要改、不要删、不要重复。
  flag         游戏原始标记（1 = 含中日韩字形，0 = 纯拉丁）。仅作参考，
               插件不读它，改了一般也没用，建议别动。
  zh           显示出来的中文。← 你只需要改这一列
  jp_original  日文原句，仅供对照翻译，插件不读。
  en           英文原句，仅供对照翻译，插件不读。

改完直接进游戏即可，不需要重新编译任何东西。


编辑注意事项

1. 保存时必须选 UTF-8（Excel/WPS 里选「CSV UTF-8」）。
2. 单元格内如果有换行、半角逗号或双引号，整格必须用英文双引号包起来；
   文字内部要出现双引号，就写成两个连续的双引号。用表格软件编辑会自动处理，
   用记事本手改就要自己注意。
3. 下面这些标记是游戏功能，不是文字，必须原样保留：

   {0}                        数值占位，例：等級 {0}
   <#FFE5B6>…</color>         颜色标签
   <sprite name="HP">         图标引用
   \NM01、\N00                人名 / 变量占位（1646 条文本里有）
   ⏎                          游戏自己的换行标记

4. key 列一旦改动，那条文本就会退回游戏自带的机翻版本（不会报错，只是没生效）。

关于缺字（显示成 □）

    游戏自带字体只有约 3200 个字形，超出的一律是方框。本补丁挂了一套动态字体
    （Noto Sans CJK TC）兜底，所以常用汉字、日文假名都可以放心用。
    如果某个极生僻的字仍然显示成方框，说明它不在 Noto Sans CJK 覆盖范围内。

    注意：游戏自带图集里有 24 个简体码位（书冯单历将开敌断来毕渗硛约纳莱萨讯试
    败费过连阶），它们能直接显示，所以写了就是简体，不会被自动转成繁体。


恢复出厂汉化

删掉 BepInEx\plugins\FM1RZhPatch\zh.csv 即可让文本回到游戏自带的机翻版本
（字体兜底仍然保留）。
